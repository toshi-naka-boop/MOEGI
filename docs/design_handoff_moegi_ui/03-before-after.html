チェックリストの変更点

改定前（BEFORE）

  • バイタルサインの記録
  • 変指定訪問看護の実施に要した時間の記録
  • 変訪問日数・訪問頻度の記録
  • 家族への指導・説明
  • 変特記事項

改定後（AFTER）

  • バイタルサインの記録
  • 変実施時間を記録し、標準実施時間を下回る場合はやむを得ない事情を確認・記録
  • 変訪問日数・訪問頻度の記録＋頻回の短時間訪問がないことの確認
  • 家族への指導・説明
  • ＋特記事項＋短時間訪問の頻回実施の確認結果を記載
