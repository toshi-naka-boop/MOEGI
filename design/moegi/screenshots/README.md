## 全画面共通で見えている課題

1. **見出しに `design.md §6.5` のような内部参照が出ている** — 開発中の名残。本番では消したい
2. **注意書き（`.run-warning`）が多すぎる** — 同じ見た目の黄色い箱が積み重なり、どれが重要か分からない
3. **状態の色分けが弱い** — 通過・停止・送信待ちがどれも同系色のチップで表現されている
4. **待ち時間の表現が無い** — 更新案の生成は約47秒かかるが、ボタンが無効化されるだけ
5. **カードが縦に長い** — 特に承認画面。1件を確認するのに何度もスクロールする
